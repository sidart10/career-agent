# Prepare a first application

Complete onboarding first and verify `career onboarding status --json` has no incomplete phase. Then:

1. Capture the opportunity with `career opportunity add --help`; preserve the posting and source URL.
2. Review the deterministic evaluation and resolve missing evidence instead of inventing experience.
3. Create an application only after deciding to pursue it.
4. Prepare application documents from confirmed facts and the preserved posting.
5. Validate and release immutable document artifacts, then use `career release upload-copy` for portal-safe filenames.
6. Resolve application questions through governed answer commands. Sensitive values require explicit retention and reuse choices.
7. Prepare and inspect the canonical submission payload.

Stop there for the supported 0.1 preparation workflow. Browser-assisted portal submission is experimental and requires a separate trusted approval, immediate payload revalidation, and observed employer confirmation. Never infer success from a click or retry an uncertain attempt.
