# Career Agent

Career Agent is a local-first, evidence-backed workflow for one job seeker. A versioned Python CLI owns governed state, while one portable set of Agent Skills orchestrates the same contracts from Claude Code and Codex.

The V1 release gate uses synthetic candidate data and a loopback-only fake employer portal. Automated tests never contact a real employer, submit a real application, upload personal documents, or mutate a real inbox or workspace.
